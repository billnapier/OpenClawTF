# Quickstart: Gemini Multi-Model Routing

## Verification Commands

Run the automated verification suite for model routing:

```bash
bash scripts/test_model_routing.sh
```

## Slash Commands Overview
- `/model flash`: Switch active session model to `gemini-2.5-flash`.
- `/model pro`: Switch active session model to `gemini-2.5-pro`.
- `/model status`: View current model configuration.
